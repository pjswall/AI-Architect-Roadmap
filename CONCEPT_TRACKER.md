## Status rubric

- **Not started:** No focused lesson yet.
- **Learning:** Explanation/example begun, understanding unverified.
- **Understood:** Can explain it independently and handle a simple question.
- **Implemented:** Has run or written code and captured reproducible evidence.
- **Revised:** Revisited after time and passed a new question or exercise.

## Learning workflow

1. Define a term in simple language and give an analogy.
2. Predict the behavior of a short Python program.
3. Run or implement it; inspect unexpected output.
4. Connect it to an AI/backend production example.
5. Discuss trade-offs and at least one failure mode.
6. Link evidence and move status only when earned.

**Career preference:** 70–80% hands-on technical work; target Staff/Principal AI Engineer or hands-on AI Architect. Management is optional, not the default destination.

**Next checkpoint:** Ask the learner to predict the output of the first synchronous Python example, then move to the async version. Avoid assuming prior knowledge of terminology.
