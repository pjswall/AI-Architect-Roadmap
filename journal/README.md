# Learning and architecture journal

Use one Markdown file per week (e.g. `2026-W44.md`). Add links to GitHub Issues/PRs and measurable evidence.

## Weekly template

### Goal
What architectural question am I answering?

### Mental model
Explain in plain language and give a concrete example.

### Implementation
What minimal implementation or experiment did I complete?

### Evidence
Commit/PR, test, benchmark, diagram or short case study.

### Trade-offs and failure paths
How does the chosen design fail? What alternatives were rejected?

### Teach-back
Explain the concept as if in a Staff/Principal engineer interview.

### Next action
One checkable task.
